GROOM PRO LIVE installed build

Open http://127.0.0.1:5000/live

Includes camera/mic, automatic vision every 5 seconds, manual questions, browser speech input when supported, GROOM TTS replies, camera toggle, mic mute and end call.

This uses the existing /live_vision and /voice endpoints. It is NOT the official low-latency Gemini Live streaming API yet; it is a ready camera+vision+voice Live mode built on your current project.

One original chat-history JSON file in the supplied ZIP was CRC-corrupt and was skipped while rebuilding the archive. No source-code file was affected.
